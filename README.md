# 🎬 Nxt Watch - Video Streaming Platform

Nxt Watch is a **React-based video streaming web application** that allows users to browse, watch, and save videos. The project demonstrates concepts like **routing, API integration, authentication, theming, and responsive UI**. It is designed to simulate a simple version of platforms like **YouTube**.

---

## 🌐 Live Demo

🔗 **Website**: [Nxt Watch](https://pradeep22nxtwatch.ccbp.tech/)  

---

## ⚙️ Features

### 👥 User Features
- 📝 Login with JWT-based authentication (Frontend simulation)
- 🔍 Search videos by title
- 📺 Browse Home, Trending, Gaming, and Saved videos
- 💾 Save videos to watch later
- 👍 Like / 👎 Dislike videos
- 📱 Fully Responsive Layout for desktop and mobile
- 🌙 Light / Dark Theme toggle
- 💡 Clean & Modern UI

### 🔧 Additional Features
- 🛠️ Error handling and failure views
- ⏳ Loading state while fetching API data
- 🔒 Logout confirmation popup
- 🎥 Video playback with `react-player`

---

## 🧰 Tech Stack

| Technology       | Purpose                            |
|------------------|------------------------------------|
| **React.js**     | Frontend UI Framework              |
| **React Router** | Navigation & Routing               |
| **Styled Components** | Styling & Theming             |
| **React Player** | Video Playback                     |
| **REST APIs**    | Fetching videos, categories, details |
| **Local Storage**| Store JWT token and theme preference|

## 🚀 Getting Started

### 📦 Installation

1. **Clone the repository**
```bash
git clone https://github.com/chintpradeep22/Nxt-Watch.git
cd Nxt-Watch
```
2. **Install dependencies**
```bash
npm install
```
3. **Start the application**
```bash
npm start
```
